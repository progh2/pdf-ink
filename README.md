# 필기웹 (pdf-ink)

굿노트처럼 PDF를 가져와 그 위에 펜으로 필기하는 웹앱입니다.
로그인·서버·공유 없이 브라우저에서만 동작합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 표시되는 주소(기본 `http://localhost:5173`)를 엽니다.

1. **PDF만 올려요** 상자로 PDF를 선택합니다.
2. 첫 페이지가 보이면 하단 툴바의 **펜**으로 그립니다.
3. **이전/다음**으로 페이지를 넘깁니다.
4. 새로고침해도 같은 문서와 필기가 복원됩니다.
5. 왼쪽 위 **다른 PDF**로 업로드 화면에 돌아갑니다. 이전 파일은 점선 박스 아래 목록에서 다시 열 수 있고, 필기는 파일별로 남습니다.

PDF가 아닌 파일이나 20MB를 넘는 파일은 거절되며, 이유가 화면에 나옵니다.

## 빌드

```bash
npm run build
npm run preview
```

이 GitHub 저장소를 Vercel에 연결하고 프레임워크를 Vite로 두면 됩니다.

## 범위 (M1)

- PDF 업로드와 페이지 렌더 (`#2`)
- 페이지 위 펜 필기 (`#3`)
- localStorage 필기 저장/불러오기 (`#4`)
- 업로드 파일 검증 (`#5`)

툴바 레이아웃(#1)은 하단 플로팅이며 펜·지우개·색·굵기·페이지를 포함합니다.
모바일 터치 다듬기는 M3입니다.
