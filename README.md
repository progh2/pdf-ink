# 필기웹 (pdf-ink)

굿노트처럼 PDF를 가져와 그 위에 펜으로 필기하는 웹앱입니다.
로그인·서버·공유 없이 브라우저에서만 동작합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 표시되는 주소(기본 `http://localhost:5173`)를 엽니다.

1. **PDF만 올려요** 상자로 PDF를 선택합니다.
2. 첫 페이지가 보이면 툴바의 **슬롯 3개** 중 하나를 눌러 그립니다. 슬롯을 길게 누르거나, 이미 고른 슬롯을 한 번 더 짧게 누르면 그 슬롯의 색·굵기(1–10)만 바꿉니다. **설정**에서 **펜만**을 켜면 S펜·애플펜슬(`pointerType === "pen"`)만 획이 생기고, 손가락은 페이지를 움직입니다. 기본은 꺼져 있어서 컴퓨터 마우스로도 그릴 수 있습니다.
3. 두 손가락으로 확대/이동합니다. 위쪽 **배율 고정**을 켜면 핀치가 배율을 바꾸지 않습니다. **이전/다음**으로 페이지를 넘기거나, 설정에서 **세로 스크롤**로 이어 볼 수 있습니다.
4. 좁은 세로 화면에서는 툴바가 위에 옵니다. 설정에서 위/왼/오/아래로 옮길 수 있습니다.
5. 새로고침해도 같은 문서와 필기가 복원됩니다.
6. 왼쪽 위 **다른 PDF**로 업로드 화면에 돌아갑니다. 이전 파일은 점선 박스 아래 목록에서 다시 열 수 있고, 필기는 파일별로 남습니다.

PDF가 아닌 파일이나 20MB를 넘는 파일은 거절되며, 이유가 화면에 나옵니다.

## 빌드

```bash
npm run build
npm run preview
```

## 배포 (#16)

Vite 정적 호스팅만 사용합니다. `vercel.json`이 빌드(`npm run build`)·출력(`dist`)·SPA fallback(`index.html`)을 지정합니다. 서버·로그인·시크릿은 없습니다.

펜 기종에서 테스트할 공개 주소: https://pdf-ink.vercel.app

## 범위 (M1)

- PDF 업로드와 페이지 렌더 (`#2`)
- 페이지 위 펜 필기 (`#3`)
- localStorage 필기 저장/불러오기 (`#4`)
- 업로드 파일 검증 (`#5`)

툴바는 슬롯 3개·지우개·이전/다음·설정입니다. 위치는 설정에서 고릅니다.
모바일 핀치 확대와 세로 스크롤은 #24입니다.
