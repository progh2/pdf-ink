# 필기웹 (pdf-ink)

굿노트처럼 PDF를 가져와 그 위에 펜으로 필기하는 웹앱입니다.
로그인·서버·공유 없이 브라우저에서만 동작합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 표시되는 주소(기본 `http://localhost:5173`)를 엽니다.

1. **PDF만 올려요** 상자로 PDF를 선택합니다.
2. 첫 페이지가 보이면 한 줄 유틸리티 바의 **펜 · 형광 · 색연필 · 지우개 · 선택 · 스탬프**를 눌러 그립니다. 이미 고른 펜/형광/색연필을 다시 탭하거나 길게 누르면 팔레트(펜은 2×3)가 열립니다. 색은 바에 미니 점으로만 보이고, 팔레트에만 고를 색이 있습니다. 형광은 투명도(기본 40), 색연필은 채점 빨강입니다. 펜·형광·색연필로 한 섭을 긋고 끝에서 400ms 기다리면 후보 도형이 40% 고스트로 뜨고 종이 위에 직선·사각·원 칩이 나옵니다. 칩을 눌러야 도형이 되고, 안 고르면 손 획입니다. 스탬프를 고른 뒤 페이지를 탭하면 문구가 안에 있는 빨간 타원 도장 한 장이 필기 레이어에 남습니다. 선택한 뒤 모서리로 비율을 유지한 채 크기를 바꿀 수 있습니다. 선택 도구는 획의 잉크(굵기+여유 6px)를 눌러야 잡히고, 선택 바는 고른 것을 가리지 않게 아래가 좁으면 위로 뒤집힙니다. **설정**에서 **펜만**을 켜면 S펜·애플펜슬(`pointerType === "pen"`)만 획/도장이 생기고, 손가락은 페이지를 움직입니다. 기본은 꺼져 있어서 손가락·마우스로도 그릴 수 있고, 한 손가락으로 쓰는 동안 페이지는 밀리지 않습니다.
3. 위쪽 **자물쇠** 옆에 **보기**/**편집**이 보입니다. 보기면 획이 안 생기고 스크롤·핀치만 되며, 그리려 하면 한 줄 **보기 중**이 뜹니다. 툴바는 바 하나뿐입니다. **되돌리기**와 **다시 실행**이 바로 보이고, 되돌리기를 길게(400ms) 눌러도 다시 실행됩니다. ⋯에는 영역캡처, 전체화면, 이미지, 회전(왼쪽/오른쪽), 미리보기, 저장, 내보내기가 있습니다. **저장**은 필기를 이 브라우저에 남기고 곧바로 주석이 박힌 PDF(`이름-필기.pdf`)를 내려받습니다. **내보내기**는 같은 PDF를 공유 시트로 보내고, 공유가 안 되는 브라우저면 같은 파일을 내려받습니다. 원래 페이지는 글자를 고른 채로 남고 필기·스탬프·이미지만 위에 얹히며, 마스킹한 페이지만 통째 그림으로 구워 가린 글자를 지웁니다. 미리보기 **개요** 탭의 목차는 PDF 책갈피로 박힙니다. 페이지는 헤더의 **1 / 2** 옆에서 넘깁니다. 영역캡처로 상자를 그리면 점선이 남고, 길게(400ms) 누르거나 오른쪽 클릭하면 복사·복제·삭제·캡처·마스킹 메뉴가 종이 위에 납니다. 두 손가락으로 확대/이동합니다. 설정에서 **배율 고정**을 켜면 핀치가 배율을 바꾸지 않습니다. 설정에서 **세로 스크롤**로 이어 볼 수 있습니다.
4. 왼쪽 그립을 길게 끌어 **위·아래·왼쪽·오른쪽** 고정 또는 떠 있게 둡니다. 왼·오는 같은 캡슐이 세로로 서고, 설정의 **툴바 위치**에서도 고를 수 있습니다. 바는 종이 위에 겹칩니다. 종이 크기·비율은 줄이지 않습니다.
5. 새로고침해도 같은 문서와 필기·개요(목차)가 복원됩니다. 미리보기 서랍의 **개요** 탭에서 항목을 넣고 고치고 지울 수 있습니다. 개요는 내보낸 PDF 안에 책갈피로 박힙니다(#54).
6. 왼쪽 위 **다른 PDF**로 업로드 화면에 돌아갑니다. 이전 파일은 점선 박스 아래 목록에서 다시 열 수 있고, 필기는 파일별로 남습니다. 이름이 같은 파일이 둘이면 카드에 마지막으로 연 시각이 같이 나옵니다.

PDF가 아닌 파일이나 20MB를 넘는 파일은 거절되며, 이유가 화면에 나옵니다.

## 빌드

```bash
npm run build
npm run preview
```

## 배포 (#16)

Vite 정적 호스팅만 사용합니다. `vercel.json`이 빌드(`npm run build`)·출력(`dist`)·SPA fallback(`index.html`)을 지정합니다. 서버·로그인·시크릿은 없습니다.

펜 기종에서 테스트할 공개 주소: https://pdf-ink.vercel.app

## 범위 (M1)

- PDF 업로드와 페이지 렌더 (`#2`)
- 페이지 위 펜 필기 (`#3`)
- localStorage 필기 저장/불러오기 (`#4`)
- 업로드 파일 검증 (`#5`)

툴바는 굿노트 4 스타일 바 하나(펜·형광·색연필·지우개·선택·스탬프·되돌리기·다시 실행·⋯)입니다. 왼쪽 그립을 끌어 위/아래/떠 있게 둡니다.
페이지는 헤더에서 넘깁니다. 모바일 터치 필기는 #11, 핀치 확대와 세로 스크롤은 #24입니다.
