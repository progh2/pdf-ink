# 필기웹 (pdf-ink)

굿노트처럼 PDF를 가져와 그 위에 펜으로 필기하는 웹앱입니다.
로그인·서버·공유 없이 브라우저에서만 동작합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 표시되는 주소(기본 `http://localhost:5173`)를 엽니다.

1. **PDF 열기**로 PDF를 선택합니다.
2. 첫 페이지가 보이면 **펜**으로 그립니다.
3. **이전/다음**으로 페이지를 넘깁니다.
4. 새로고침해도 같은 문서와 필기가 복원됩니다.

PDF가 아닌 파일이나 20MB를 넘는 파일은 거절되며, 이유가 화면에 나옵니다.

## 빌드

```bash
npm run build
npm run preview
```

## 범위 (M1)

- PDF 업로드와 페이지 렌더 (`#2`)
- 페이지 위 펜 필기 (`#3`)
- localStorage 필기 저장/불러오기 (`#4`)
- 업로드 파일 검증 (`#5`)

색·굵기·지우개와 모바일 터치 다듬기는 이후 마일스톤입니다.
