# 필기웹 (pdf-ink)

굿노트처럼 PDF를 가져와 그 위에 펜으로 필기하는 웹앱입니다.
로그인·서버·공유 없이 브라우저에서만 동작합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 표시되는 주소(기본 `http://localhost:5173`)를 엽니다.

1. **PDF만 올려요** 상자로 PDF를 선택합니다. 아래 **드롭박스에서 열기**(그리고 키가 설정돼 있으면 **구글 드라이브에서 열기**)로 클라우드의 PDF를 바로 열 수도 있습니다(처음 한 번 드롭박스 로그인, 토큰은 이 브라우저에만 남고 **연결 끊기**로 지웁니다).
2. 첫 페이지가 보이면 한 줄 유틸리티 바의 **펜 · 형광 · 색연필 · 지우개 · 선택 · 스탬프**를 눌러 그립니다. 이미 고른 펜/형광/색연필을 다시 탭하거나 길게 누르면 팔레트(펜은 2×3)가 열립니다. 색은 바에 미니 점으로만 보이고, 팔레트에만 고를 색이 있습니다. 형광은 투명도(기본 40), 색연필은 채점 빨강입니다. 획은 펜이 보고하는 표본을 모두 받아 곡선으로 이어 그리고, 그리는 동안에는 그 획만 따로 얹어 필기가 쌓여도 느려지지 않습니다. 펜·형광·색연필로 한 섭을 긋고 끝에서 400ms 기다리면 후보 도형이 40% 고스트로 뜨고 종이 위에 직선·사각·원 칩이 나옵니다. 칩을 눌러야 도형이 되고, 안 고르면 손 획입니다. 스탬프를 고른 뒤 페이지를 탭하면 문구가 안에 있는 빨간 타원 도장 한 장이 필기 레이어에 남습니다. 선택한 뒤 모서리로 비율을 유지한 채 크기를 바꿀 수 있습니다. 선택 도구는 획의 잉크(굵기+여유 6px)를 눌러야 잡히고, 고정한 이미지 위를 길게 누르면 **고정 해제** 메뉴가 뜨며, 선택 바는 고른 것을 가리지 않게 아래가 좁으면 위로 뒤집힙니다. S펜처럼 **옆 버튼이 있는 펜**은 버튼을 누른 채 그으면 그 획만 지우개가 됩니다. 버튼이 둘인 펜은 설정의 **펜 버튼**(아래)과 **두 번째 버튼**에서 각각 지우개·선택·없음을 고릅니다(기본은 지우개·선택). 지우개는 도구를 바꾸지 않고 버튼을 떼면 원래 펜으로 돌아오며, 선택은 고른 것을 다뤄야 하므로 선택 도구가 켜집니다. **펜을 뒤집은 지우개 꼭지는 언제나 지우개**입니다. 설정의 **펜 버튼 지우개**로 전부 끌 수 있습니다. **설정**에서 **펜만**을 켜면 S펜·애플펜슬(`pointerType === "pen"`)만 획/도장이 생기고, 손가락은 페이지를 움직입니다. 기본은 꺼져 있어서 손가락·마우스로도 그릴 수 있고, 한 손가락으로 쓰는 동안 페이지는 밀리지 않습니다.
3. 문서를 열면 **보기(잠금)로 시작**합니다. 그 사이에 드롭박스 문서면 다른 기기가 고쳤는지 확인하고, 바뀌었으면 한 줄로 **새로 불러오기**를 권합니다(자동으로 바꾸지 않습니다). **보기**/**편집** 자물쇠도 제목 왼편에 있습니다(폰에서 제목에 가리지 않게). 보기면 획이 안 생기고 스크롤·핀치만 되며, 그리려 하면 한 줄 **보기 중**이 뜹니다. 툴바는 바 하나뿐입니다. **되돌리기**와 **다시 실행**이 바로 보이고, 되돌리기를 길게(400ms) 눌러도 다시 실행됩니다. **미리보기**는 헤더 왼쪽 위(다른 PDF 옆) 아이콘이고, 눌러 두면 종이를 만지거나 획을 그어도 열린 채 남습니다(오른쪽 가장자리를 끌어 96~360으로 폭을 바꾸면 그대로 기억합니다). ⋯에는 전체화면, 이미지, 스티커, 회전(왼쪽/오른쪽), 저장, 내보내기가 있습니다. **영역캡처는 선택 칸이 겸합니다** — 선택 도구로 상자를 끌었을 때 잡히는 게 없으면 점선 영역이 남습니다. **저장**은 필기를 이 브라우저에 남기고, 드롭박스에서 연 문서면 **그 드롭박스 파일에 다시 씁니다**(그 사이 다른 기기가 고쳤으면 덮어쓰지 않고 알려 줍니다). 원본에 다시 쓴 뒤에는 그 필기가 파일 안으로 들어갔으므로 브라우저에 있던 같은 필기는 지웁니다 — 다시 열 때 두 겹으로 보이지 않게 합니다. 크롬처럼 파일 핸들을 주는 브라우저에서는 **연 원본 파일에 그대로 덮어씁니다**(처음 한 번 브라우저가 쓰기 허락을 묻습니다). 핸들이 없는 사파리·iOS나 허락을 거절하면 주석이 박힌 PDF(`이름-필기.pdf`)를 내려받습니다. **내보내기**는 같은 PDF를 공유 시트로 보내고, 공유가 안 되는 브라우저면 같은 파일을 내려받습니다. 원래 페이지는 글자를 고른 채로 남고 필기·스탬프·이미지만 위에 얹히며, 마스킹한 페이지만 통째 그림으로 구워 가린 글자를 지웁니다. 미리보기 **목차** 탭의 항목은 PDF 책갈피로 박힙니다. 페이지는 헤더의 **1 / 2** 옆에서 넘깁니다. 선택 도구로 빈 곳에 상자를 그리면 점선이 남고, 길게(400ms) 누르거나 오른쪽 클릭하면 복사·복제·삭제·캡처·마스킹 메뉴가 종이 위에 납니다. 두 손가락으로 확대/이동합니다(최대 8배). 확대를 멈추면 그 배율에 맞춰 쪽을 다시 그려 글자와 획이 또렷해집니다. 설정에서 **배율 고정**을 켜면 핀치가 배율을 바꾸지 않습니다. 설정에서 **세로 스크롤**로 이어 볼 수 있습니다.
4. 왼쪽 그립을 길게 끌어 **위·아래·왼쪽·오른쪽** 고정 또는 떠 있게 둡니다. 왼·오는 같은 캡슐이 세로로 서고, 설정의 **툴바 위치**에서도 고를 수 있습니다. 바는 종이 위에 겹칩니다. 종이 크기·비율은 줄이지 않고, 대신 상하좌우로 바 두께만큼(64) 밀 수 있어 바에 가린 자리도 밀어서 봅니다. 세로 스크롤에서는 첫 장 위·마지막 장 아래로 같은 만큼 더 스크롤됩니다.
5. 미리보기 서랍의 쪽을 **길게(400ms) 누르거나 오른쪽 클릭**하면 복사·붙여넣기·복제·삭제·위로·아래로·왼쪽 90°·오른쪽 90° 메뉴가 종이 위에 납니다(마지막 한 장은 못 지웁니다). 길게 눌러 잡은 채로 끌면 순서가 바뀌고, 필기도 그 쪽을 따라갑니다. 복제·붙여넣기로 생긴 쪽은 필기를 따로 가집니다. 순서 바꾸기는 **전체** 목록에서만 됩니다.
6. 새로고침해도 같은 문서와 필기·개요(목차)가 복원됩니다. 미리보기 서랍의 **목차** 탭에서 항목을 넣고, 줄을 **탭하면 그 쪽으로 가고 길게(400ms) 누르면 이름 변경·삭제** 메뉴가 뜹니다. 줄 왼쪽에 `p5.`처럼 지금 쪽 번호가 나옵니다. 목차 항목은 쪽 번호가 아니라 그 쪽 자체를 가리켜서, 순서를 바꾸거나 앞에 쪽을 넣어도 같은 쪽으로 갑니다(그 쪽을 지우면 항목도 함께 사라집니다). 목차는 내보낸 PDF 안에 책갈피로 박힙니다(#54). 페이지 탭의 **빈 쪽**은 목차와 다른 것으로, 바로 앞 쪽과 같은 크기의 필기용 백지 한 장입니다(글자 없는 흰 종이).
7. ⋯의 **스티커**로 그림에서 스티커를 만듭니다. 그림 한 장을 고르고 영역을 여러 번 끌면 **각 사각형이 스티커 한 장**이 되고, **전체 넣기**로 통째 한 장도 됩니다. 그린 영역은 탭해 고른 뒤 안을 끌어 옮기고, 모서리로 크기를 바꾸고, `✕`로 지웁니다. 만든 스티커는 **길게(400ms) 누르면 편집·삭제 메뉴**가 뜨고, 길게 눌러 잡은 채 끌면 폴더 안 순서가 바뀝니다(잡기 전에 끌면 폴더로 옮기기). 폴더(기본 `미분류`)를 만들어 정리하고 스티커를 끌어 옮깁니다. 스티커를 **탭하면 종이에 놓이고**(이미지처럼 고르고 돌리고 지웁니다) 길게 눌러 뜬 메뉴의 **편집**으로 스튜디오를 열어 투명(색 찍기)·지우개·회전(자유 각)·모서리 크기를 고칩니다. 스티커는 이 브라우저(IndexedDB)에만 있고 서버에 올라가지 않습니다.
8. 왼쪽 위 **다른 PDF**로 업로드 화면에 돌아갑니다. 이전 파일은 점선 박스 아래 목록에서 다시 열 수 있고, 필기는 파일별로 남습니다. 이름이 같은 파일이 둘이면 카드에 마지막으로 연 시각이 같이 나옵니다.

PDF가 아닌 파일이나 20MB를 넘는 파일은 거절되며, 이유가 화면에 나옵니다.

## 설치 (PWA)

브라우저의 **설치**(또는 홈 화면에 추가)로 앱처럼 쓸 수 있습니다. 설치하면 주소창이 사라져 종이가 더 넓게 나오고, 앱 껍데기와 PDF 엔진이 캐시돼 **오프라인에서도 최근 문서를 엽니다**. 새 버전이 준비되면 한 줄로 알리고 **새로고침**을 누를 때 바뀝니다(조용히 옛 화면을 계속 주지 않습니다).

문서를 처음 열 때 브라우저에 **저장공간 유지**를 한 번 요청합니다. 필기는 이 기기에만 있어서, 허락해 두면 브라우저가 공간을 정리할 때 필기가 지워지지 않습니다.

## 빌드

```bash
npm run build
npm run preview
```

## 배포 (#16)

Vite 정적 호스팅만 사용합니다. `vercel.json`이 빌드(`npm run build`)·출력(`dist`)·SPA fallback(`index.html`)을 지정합니다. 서버·로그인·시크릿은 없습니다.

펜 기종에서 테스트할 공개 주소: https://pdf-ink.vercel.app

## 범위 (M1)

- PDF 업로드와 페이지 렌더 (`#2`)
- 페이지 위 펜 필기 (`#3`)
- localStorage 필기 저장/불러오기 (`#4`)
- 업로드 파일 검증 (`#5`)

툴바는 굿노트 4 스타일 바 하나(펜·형광·색연필·지우개·선택·스탬프·되돌리기·다시 실행·⋯)입니다. 왼쪽 그립을 끌어 위/아래/떠 있게 둡니다.
페이지는 헤더에서 넘깁니다. 모바일 터치 필기는 #11, 핀치 확대와 세로 스크롤은 #24입니다.
