# 필기웹 (pdf-ink) — 제품 정의

마지막 갱신: 2026-09-18 · 저장소: https://github.com/progh2/pdf-ink · 배포: https://pdf-ink.vercel.app

## 한 줄

굿노트처럼 PDF 위에 펜으로 필기하는 웹앱. **서버도 로그인도 없다.**

## 원칙 (모든 결정의 기준)

1. **서버 없음.** 정적 호스팅뿐. 필기 원문은 우리 쪽 어디에도 남지 않는다.
2. **종이가 먼저.** 크롬(툴바·서랍)이 종이 크기·비율을 깎지 않는다. 예외는 미리보기 서랍 하나(#155, 마스터 지시).
3. **바 하나.** 굿노트4 스타일 유틸리티 바 한 줄. 두 번째 알약·레일을 만들지 않는다.
4. **조용히 이기지 않는다.** 남의 수정을 덮어쓰지 않고, 지운 것은 되돌릴 수 있고, 실패는 한 줄로 말한다. 브라우저 대화상자는 쓰지 않는다 — 배너로 묻고 「한 번 더」로 받는다.
5. **이슈 먼저.** 새 일은 이슈로 만들고, 완료 기준(잠금·깨진 목록)만 맞춘다.
6. **잠금 문구도 갱신 대상이다.** 닫힌 이슈의 옛 명세가 마스터의 새 요청을 이기지 못한다(#435에서 배웠다).

## 사용자

교사·학생(마스터: 고등학교 교사). 기기는 윈도우 데스크톱(마우스), 갤럭시 폰·태블릿(S펜, 삼성브라우저), 아이패드(사파리). 학교와 집 두 곳에서 같은 문서를 이어 쓴다.

## 지금 되는 것

### 종이와 필기
- PDF 열기·렌더·쪽 넘김·세로 스크롤. 상한은 기기 메모리별 **80 · 120 · 200MB**
- 펜·형광(납작한 팁)·색연필·지우개(획/픽셀)·**손바닥**·선택. 팔레트에서 색을 고르고, 색 칸을 길게 눌러 **직접 조색**(흰색 포함, 최근 5색). 굵기는 0.5부터 반 칸 단위, 스포이드로 화면 색 집기
- 획 끝에서 400ms 멈추면 직선·사각·원 칩. 고르지 않으면 손 획 그대로
- 핀치로 **0.7~8배**, 멈추면 그 배율로 다시 렌더. PC는 헤더 ＋/－와 Ctrl+휠
- 종이를 상하좌우 64px 밀 수 있고, 빠르게 튕기면 관성으로 넘어간다
- 펜을 띄우면 닿을 자리가 지금 색·굵기로 보이고, 마우스 커서는 도구를 따른다
- 이미지·스티커를 놓고 돌리고 고정한다. 붙인 그림은 원본 해상도를 지킨다

### 문서 다루기
- 미리보기 서랍(폭 96~360, 열어 둔 채 필기 가능, 본문을 밀어냄, 썸에 필기 포함)
- 쪽 복사·붙여넣기·복제·삭제·순서·회전. **여러 쪽 골라 한 번에**. 그림·PDF를 지금 쪽 다음에 끼우기
- 목차(쪽 자체를 가리킴, 더블탭 이름 변경)와 책갈피 — 내보낸 PDF에 박힌다
- 영역 지정 → 복사·복제·삭제·캡처·마스킹
- PDF 링크 따라가기와 **끊긴 링크 고치기**(같은 목적지 일괄 수정, 사이드카에 담겨 기기 간 이동)
- **필기 옮기기** — 다른 판의 같은 쪽을 글자·그림으로 찾아 필기를 가져온다

### 저장과 동기
| 무엇 | 어디에 |
|---|---|
| 필기·쪽 구성·목차 | 이 브라우저(localStorage, 넘치면 IndexedDB 대체 저장) + 클라우드 사이드카 `<이름>.pdf.ink` |
| PDF 원본 | 열어 온 곳(로컬 파일·드롭박스·구글 드라이브) + 다시 열기용 사본(IndexedDB) |
| 쪽 그림 | IndexedDB(기기별). 문서별 설정으로 `<이름>.pdf.thumbs` 공유 |
| 스티커 | IndexedDB + (고르면) 드롭박스·드라이브 |

- **저장** = 사이드카만 올린다(KB 단위, 필기는 계속 고칠 수 있다). 클라우드 문서는 **2.5초 디바운스로 자동 저장**
- **합치기** = 항목 단위 병합 + 무덤(지운 것은 지워진 채로). 열어 두면 20초마다 받는다
- **PDF에 굽기** = 주석이 박힌 PDF를 원본에 다시 쓴다(남에게 보낼 때). 그때 필기는 굳는다
- **내보내기** = 주석 박힌 PDF를 공유 시트나 다운로드로. 글자는 고를 수 있게 남고 마스킹한 쪽만 그림으로 굽는다
- **다른 이름으로 저장** = 드롭박스의 원하는 폴더에 사본(필기 없이·옆 파일로·구워서)
- 다른 기기가 파일을 고치면 알리고 **묻고 나서** 불러온다. 덮어쓰지 않는다

### 기기 저장 공간
- 첫 화면에서 **목록 ↔ 표지** 보기를 고른다. 표지는 1쪽을 그려 캐시하고 제목은 그 아래
- 문서를 **개별·전체로 지운다.** 지우면 본문·필기·이미지·쪽 그림·링크 고침까지 함께 사라진다
- **쓴 양과 남은 양**을 첫 화면에 보여 준다. 공간이 차면 다시 그리면 그만인 쪽 그림 캐시를 먼저 비우고 저장을 재시도한다

### 설치와 보안
- PWA. 오프라인에서 최근 문서가 열리고, 새 버전은 한 줄 알림 뒤 사용자가 새로고침할 때 적용된다
- 문서를 열 때 저장공간 유지를 한 번 요청한다
- 배포에 **CSP**를 건다 — 스크립트는 우리 것만, 연결은 드롭박스·드라이브 원본만. 붙여넣은 HTML의 이미지는 `data:` 래스터만 통과시킨다
