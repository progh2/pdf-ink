# 필기웹 (pdf-ink) — 제품 정의

마지막 갱신: 2026-09-03 · 저장소: https://github.com/progh2/pdf-ink · 배포: https://pdf-ink.vercel.app

## 한 줄

굿노트처럼 PDF 위에 펜으로 필기하는 웹앱. **서버도 로그인도 없다.**

## 원칙 (모든 결정의 기준)

1. **서버 없음.** 정적 호스팅뿐. 필기 원문은 우리 쪽 어디에도 남지 않는다.
2. **종이가 먼저.** 크롬(툴바·서랍)이 종이 크기·비율을 깎지 않는다. 예외는 미리보기 서랍 하나(#155, 마스터 지시).
3. **바 하나.** 굿노트4 스타일 유틸리티 바 한 줄. 두 번째 알약·레일을 만들지 않는다.
4. **조용히 이기지 않는다.** 남의 수정을 덮어쓰지 않고, 지운 것은 되돌릴 수 있고, 실패는 한 줄로 말한다.
5. **이슈 먼저.** 새 일은 이슈로 만들고, 완료 기준(잠금·깨진 목록)만 맞춘다.

## 사용자

교사·학생(마스터: 고등학교 교사). 기기는 윈도우 데스크톱(마우스), 안드로이드 폰·태블릿(S펜), 학교와 집 두 곳.

## 지금 되는 것

### 종이와 필기
- PDF 업로드(20MB 이하)·렌더·페이지 넘김·세로 스크롤
- 펜·형광·색연필·지우개·선택·스탬프. 팔레트에서 색을 고르고, 색 칸을 길게 눌러 **직접 조색**(흰색 포함, 최근 5색 저장)
- 획 끝에서 400ms 멈추면 직선·사각·원 칩. 고르지 않으면 손 획 그대로
- 핀치로 **0.7~8배**. 확대를 멈추면 그 배율로 다시 렌더해 또렷하게
- 종이를 상하좌우 64px 밀 수 있어 툴바에 가린 자리도 본다
- 펜 버튼(배럴·두 번째·지우개 꼭지)에 지우개/선택/없음을 배정
- 이미지·스티커를 종이에 놓고 돌리고 고정한다

### 문서 다루기
- 미리보기 서랍(폭 96~360, 열어 둔 채 필기 가능, 본문을 밀어냄)
- 쪽 복사·붙여넣기·복제·삭제·순서·회전. **여러 쪽 골라 한 번에**
- 목차(쪽 순서에 삽입, 더블탭으로 이름 변경)와 책갈피
- 영역 지정 → 복사·복제·삭제·캡처·마스킹·다른 쪽/URL 연결

### 저장과 동기
| 무엇 | 어디에 |
|---|---|
| 필기·잎·목차 | 이 브라우저(localStorage) + 클라우드 사이드카 `<이름>.pdf.ink` |
| PDF 원본 | 열어 온 곳(로컬 파일·드롭박스·구글 드라이브) |
| 썸네일 | IndexedDB(기기별). 문서별 설정으로 `<이름>.pdf.thumbs` 공유 |
| 스티커 | IndexedDB(기기별) |

- **저장** = 사이드카만 올린다(KB 단위, 필기는 계속 고칠 수 있다). 드롭박스·드라이브 문서는 **2.5초 디바운스로 자동 저장**
- **PDF에 굽기** = 주석이 박힌 PDF를 원본에 다시 쓴다(남에게 보낼 때). 그때 필기는 굳는다
- **내보내기** = 주석 박힌 PDF를 공유 시트나 다운로드로
- **다른 이름으로 저장** = 드롭박스의 원하는 폴더에 사본(필기 없이·옆 파일로·구워서)
- 다른 기기가 파일을 고치면 알리고 **묻고 나서** 불러온다. 덮어쓰지 않는다

### 설치
PWA. 오프라인에서 최근 문서가 열리고, 새 버전은 한 줄 알림 뒤 사용자가 새로고침할 때 적용된다. 문서를 열 때 저장공간 유지를 한 번 요청한다.
