# 필기웹 진행 방식

저장소: https://github.com/progh2/pdf-ink
팀장: 제타
역할: 기획, 디자인, 개발, 검수, 평가, 보안

## 마일스톤
- M1 기본필기: 업로드·렌더·펜·로컬저장·검증
- M2 툴바·획: 왼/오 겹침, 획 굵기, 슬롯
- M3 필기도구: 형광·팔레트·색연필·스탬프
- M4 편집기: 보기/편집·되돌리기·마스킹·영역캡처·전체화면·선택

## 규칙
1. 새 일은 이슈로 만든다. 이슈 없이 코드부터 쓰지 않는다.
2. 구현은 해당 이슈의 완료 기준만 맞춘다.
3. 진행 내용은 이슈 댓글과 이 문서에 남긴다.
4. 보안 담당은 방어적 수정만 한다. PoC·공격 절차는 쓰지 않는다.
