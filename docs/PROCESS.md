# 필기웹 진행 방식

저장소: https://github.com/progh2/pdf-ink
팀장: 제타
역할: 기획, 디자인, 개발, 검수, 평가, 보안

## 마일스톤
- M1 MVP: 업로드, 페이지 보기, 펜, 로컬 저장, 업로드 검증
- M2 도구: 색·굵기·지우개, 줌/페이지
- M3 다듬기: 모바일 터치, 사용성 평가 반영

## 규칙
1. 새 일은 이슈로 만든다. 이슈 없이 코드부터 쓰지 않는다.
2. 구현은 해당 이슈의 완료 기준만 맞춘다.
3. 진행 내용은 이슈 댓글과 이 문서에 남긴다.
4. 보안 담당은 방어적 수정만 한다. PoC·공격 절차는 쓰지 않는다.

## 진행
- 이슈 생성: #8 기획(MVP 범위와 사용 흐름), #10 색·굵기·지우개(M2), #11 모바일 터치 필기(M3).
- GitHub 마일스톤(M1 MVP / M2 tools / M3 polish)과 프로젝트 「필기웹」은 현재 토큰 권한(403)으로 만들지 못했다. 이슈에는 라벨로 마일스톤을 표시했다.
- M1 개발·보안(#2 #3 #4 #5) Vite 앱으로 구현. `npm run dev`로 실행.
- #1 디자인 값(배경, 하단 플로팅 툴바, 업로드 점선 박스, 44px 터치)을 UI에 맞춤.
- #8: 필기 화면 왼쪽 위 “다른 PDF”로 업로드로 돌아감. 세션은 새 파일 선택 시에만 갱신.
- #8 검수: “다른 PDF” 후 파일 창이 바로 뜨던 누수를 막음. 점선 박스를 다시 눌러야 창.
- #13: 업로드 화면 점선 박스 아래 IndexedDB 최근 목록. 행을 누르면 그 파일+잉크로 다시 연다.
- #15: 올리기/필기 크롬을 굿노트처럼. 크림 책상 `#F3F0E8`, 위 줄에 “다른 PDF”+가운데 문서 이름, 하단 캡슐 툴바(#1 토큰), 점선 박스 아래 320×56 문서 카드.
- #16: Vercel Vite 정적 호스팅용 vercel.json. 서버·인증 없음. 이 환경에서는 공개 URL을 만들지 못함.
