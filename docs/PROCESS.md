# 필기웹 진행 방식

저장소: https://github.com/progh2/pdf-ink
팀장: 제타
역할: 기획, 디자인, 개발, 검수, 평가, 보안

## 마일스톤
- M1 기본필기: 업로드·렌더·펜·로컬저장·검증
- M2 툴바·획: 왼/오 겹침, 획 굵기, 슬롯
- M3 필기도구: 형광·팔레트·색연필·스탬프
- M4 편집기: 보기/편집·되돌리기·마스킹·영역캡처·전체화면·선택

## 규칙
1. 새 일은 이슈로 만든다. 이슈 없이 코드부터 쓰지 않는다.
2. 구현은 해당 이슈의 완료 기준만 맞춘다.
3. 진행 내용은 이슈 댓글과 이 문서에 남긴다.
4. 보안 담당은 방어적 수정만 한다. PoC·공격 절차는 쓰지 않는다.

## 진행
- 이슈 생성: #8 기획(MVP 범위와 사용 흐름), #10 색·굵기·지우개(M2), #11 모바일 터치 필기(M3).
- GitHub 마일스톤(M1 MVP / M2 tools / M3 polish)과 프로젝트 「필기웹」은 현재 토큰 권한(403)으로 만들지 못했다. 이슈에는 라벨로 마일스톤을 표시했다.
- M1 개발·보안(#2 #3 #4 #5) Vite 앱으로 구현. `npm run dev`로 실행.
- #1 디자인 값(배경, 하단 플로팅 툴바, 업로드 점선 박스, 44px 터치)을 UI에 맞춤.
- #8: 필기 화면 왼쪽 위 “다른 PDF”로 업로드로 돌아감. 세션은 새 파일 선택 시에만 갱신.
- #8 검수: “다른 PDF” 후 파일 창이 바로 뜨던 누수를 막음. 점선 박스를 다시 눌러야 창.
- #13: 업로드 화면 점선 박스 아래 IndexedDB 최근 목록. 행을 누르면 그 파일+잉크로 다시 연다.
- #15: 올리기/필기 크롬을 굿노트처럼. 크림 책상 `#F3F0E8`, 위 줄에 “다른 PDF”+가운데 문서 이름, 하단 캡슐 툴바(#1 토큰), 점선 박스 아래 320×56 문서 카드.
- #16: Vercel Vite 정적 호스팅용 vercel.json. 서버·인증 없음. 이 환경에서는 공개 URL을 만들지 못함.
- #20: 필기 툴바 “펜만” 스위치. 켜면 `pointerType === "pen"`만 획/지우개. 기본 끔. localStorage에 기억.
- #22: 설정에서 툴바 위/왼/오/아래. 좁은 세로는 기본 위, 넓은 화면은 아래. 왼·오는 세로 캡슐. 「펜만」은 설정으로 옮김.
- #23: 툴바 슬롯 3개(44×44, 사이 4). 짧게 사용, 길게 색·굵기(1–10)만 수정. 패널 240×흰 카드. 펜 종류 줄 없음.
- #28: 폰에서 슬롯 길게 누르기가 `pointercancel`/`contextmenu`에 죽지 않게. 이미 고른 슬롯을 다시 짧게 눌러도 같은 색·굵기 패널. 설정 시트는 위치·보기·펜만.
- #24: 핀치 확대, 펜만 켜면 손가락 팬, 배율 고정, 페이지/세로 스크롤 보기.
- #30: 왼·오 캡슐은 종이 위에 겹친다. 워크스페이스를 깎지 않아 위/아래와 종이 크기·비율이 같다.
- #32: 획 lineWidth는 레이아웃 CSS 너비 기준. 핀치 transform·getBoundingClientRect를 쓰지 않아 그리는 중과 뗀 뒤 굵기가 같다.
- #26 #34 #35 #36: 슬롯 패널 탭 네 칸(펜·형광·색연필·스탬프). 색은 패널만(펜 6·형광 5). 형광 투명도 기본 40. 색연필 `#C23A32`. 스탬프는 패널의 빨간 원 72+다섯 문구, 탭하면 필기 레이어에 한 장. 지우개 짧게 픽셀(스탬프도 지움), 길게 획/픽셀+굵기. #31 #25는 이 슬라이스에 없음.
- #31: 헤더 자물쇠 32 `#8A8478`=보기/편집(보기는 획 없음). 툴바 캡슐은 하나(높이 56). 슬롯·지우개 반대편 같은 캡슐 끝에 되돌리기·⋯(44×44, 사이 4). 두 번째 알약/레일 space-between 없음. 이전/다음은 헤더 1/2. ⋯는 슬롯 패널과 같은 흰 카드에 마스킹·영역캡처·전체화면만. 되돌리기 스택·캡처 버퍼는 메모리만. 모자이크를 픽셀에 구운 뒤 복사 탭에서만 클립보드 PNG. #25 선택은 없음.
